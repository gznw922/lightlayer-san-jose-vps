## 三条线路的差别，看回程路由就够了

标价一样，区别全在网络。

**优化线路（Premium）**：电信回程走 CN2，移动回程走 CMIN2，联通走 9929+4837。实测回程延迟电信大多 128–177ms、移动 126–181ms，联通偏高，广东联通尤其明显；单线程上下行回程速度多在 100Mbps 以上，联通偏弱。2025 年初的一份测试记录说联通回程强制走移动 CMIN2，跟 2026 年 10 月的 9929+4837 对不上，联通这一段路由本身就会调整，别指望它像电信、移动那样固定。

**标准线路（Standard）**：国内 ping 平均约 178ms，比优化线路略高。电信去程 163 骨干网直连圣何塞，回程从圣何塞 POP 对接 163 回国；移动 CMI 去程直连、回程在圣何塞对接 CMI，双程都直连。联通是短板：去程 AS4837 直连洛杉矶再转 telia 到圣何塞，回程走 telia 绕道欧洲，在法兰克福对接联通 AS4837 回国，南方部分地区会直接在洛杉矶回来。

**国际线路（Global）**：面向全球用户，带宽大、单价低，国内访问延迟比前两条高不少，晚高峰波动更明显。访客在北美或欧洲，这条最划算。

按场景选：

- 访客在国内、家宽是电信或移动，选优化线路
- 访客在海外、主要跑下载或代理，选国际线路
- 只建个静态博客、预算卡得紧，标准线路能省一点
- 联通宽带是主力、业务对延迟敏感，三条线路都要做好波动准备，实时业务别放这台机器上

## 硬件：Platinum 9242 和一条被限制的 I/O

圣何塞宿主机用的是 Intel Xeon Platinum 9242，48 核 96 线程，基频 2.3GHz、加速 3.8GHz。优化线路 1 核 1GB 测试机的 Geekbench 5 单核成绩 820，整机 HQ 总分 20797，负载很低。

硬盘是 SSD，系统识别出 46GB 可用空间，顺序读写尚可，随机读写一般。多份测评的硬盘 I/O 集中在 225–226MB/s，标准线路 2 核 2GB 测试机是 226MB/s，优化线路机器在 225MB/s 上下。这个数字不是硬盘跑不动，是官方对单个 VM 的 I/O 做了限制，属于产品设定，不是故障。有推广文写 500–800MB/s，跟三份实际测评对不上，应以实测为准。

UnixBench 2 核 1 线程约 1589 分。跑 Nginx、PHP、Node 小应用、Docker 里的轻量服务没问题；MySQL 并发一上来就会卡在磁盘上，Elasticsearch 这类吃随机 I/O 的更不用考虑。

1GB 内存的 KVM 机器支持 balloon 回收，宿主机内存紧张时会回收一部分，实际可用余量不大。Debian 最小化安装后，跑个静态站加单个小服务够用，装面板、跑 WordPress 建议直接上 2GB。

## 常见问题

**圣何塞和洛杉矶怎么选？**
两个机房定位不同。洛杉矶的测评机型是 AMD EPYC 7H12，圣何塞是 Platinum 9242，CPU 平台不一样，洛杉矶的跑分不能套到圣何塞。选哪个看访客位置：国内访客为主选圣何塞优化线路，北美访客为主选洛杉矶。

**联通宽带能用吗？**
能连，延迟和稳定性不如电信、移动。优化线路联通走 9929+4837，标准线路联通回程绕欧洲，两种方案在晚高峰都可能抖动。联通用户如果一定要买，优先优化线路，避开实时性要求高的业务。

**1GB 内存够干什么？**
Debian 或 Ubuntu 最小化安装后余量不多，够跑 Nginx 静态站、单个小 API、一两个轻量 Docker 容器、开发测试环境。WordPress、MySQL、面板类工具建议 2GB 起。

**支持 Windows 吗？**
弹性配置里包含 Windows 10 和 Server 2008/2012/2016/2019，需要 2GB 以上内存。1GB 的入门款只能跑 Linux。
